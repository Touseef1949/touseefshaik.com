What it does

Cast Relationship Graph uses a 5-agent Agno Team powered by DeepSeek to research any movie or TV show's cast, discover character relationships, render an interactive Mermaid diagram, validate accuracy, and polish the final output — all in about 60 seconds.

🔍 Cast Discovery

Enter a movie or TV show name — the first agent researches the full cast list, including main and supporting characters.

🔗 Relationship Mapping

A second agent analyzes how characters relate to each other — family ties, alliances, rivalries, romantic connections.

📊 Interactive Mermaid Graph

The graph agent generates a color-coded Mermaid diagram. Zoom, pan, and explore connections visually.

✅ Validation Layer

A fourth agent cross-checks the graph for accuracy — missing links, duplicate nodes, wrong relationship types.

✨ Polished Output

The final agent cleans up formatting, adds labels, and ensures the graph is presentation-ready.

🆓 Free & Open Source

No signup, no paywall. Deploy your own copy. Powered by DeepSeek's multi-agent team.
