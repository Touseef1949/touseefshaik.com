What BA Assistant Does (v2)

BA Assistant v2 is an AI-powered requirement analysis tool that takes raw requirements — a paragraph, meeting notes, a PRD PDF, or even a whiteboard photo — and generates a comprehensive 14-section BA/PO report. The default modes use a single fast senior agent; Enterprise mode optionally coordinates 5 specialist agents for compliance-heavy projects.

Comprehensive mode runs in 30-90 seconds. Enterprise mode deploys all 5 agents in parallel for compliance-heavy fintech projects and finishes in 3-5 minutes.

Six analysis types are available: Comprehensive, Interactive Q&A, Enterprise, Quick Feature Extraction, User Stories, Tech Architecture, and Gap Analysis. Every report includes Mermaid diagrams and is exportable as Markdown, plain text, or branded PDF.

How It Works

The Agent Pipeline

Enterprise mode uses five specialist AI agents in a pipeline, each powered by DeepSeek V4 Flash: requirements extraction → backlog structuring → architecture design → risk assessment → diagram generation. A Team coordinator (DeepSeek V4 Pro) orchestrates them, and Gemini 3.5 Flash handles document and image extraction. Default modes (Comprehensive, User Stories, Tech Architecture, etc.) skip the orchestrator and use the most relevant specialist directly.

  1. BA Requirements Analyst — Structures raw needs into clear functional & non-functional requirements. Extracts entities, business rules, and constraints.
  2. Product Owner Analyst — Converts requirements into epics, features, and user stories with MoSCoW prioritization and backlog structure.
  3. Solution Architect — Designs technology stack, integration patterns, data models, and NFRs with deployment strategy recommendations.
  4. Risk & QA Reviewer — Identifies technical, business, and project risks. Validates completeness and cross-agent output consistency.
  5. Mermaid Diagram Designer — Generates process flows, sequence diagrams, state charts, and data flow diagrams — paste-ready for any markdown document.

Request Flow

  1. User pastes raw requirements (or uploads PDF / photo)
  2. BA Analyst structures & categorizes the input
  3. PO Analyst extracts features & user stories
  4. Solution Architect designs system & integrations
  5. Risk & QA Reviewer audits all outputs
  6. Diagram Designer generates Mermaid charts
  7. Consolidated 14-section report delivered to user

Frequently Asked Questions

What kind of requirements can I paste?

Anything — a paragraph, a user story, a PRD excerpt, meeting notes, or a full spec. BA Assistant works with natural language of any length.

Can I use this for client or enterprise data?

BA Assistant is designed for early-stage analysis and documentation support. Do not paste confidential or PII data. Always review AI-generated outputs before using them in production.

What does the report include?

Functional & non-functional requirements, features with MoSCoW prioritization, user stories with acceptance criteria, architecture recommendations, risk assessment with mitigations, and Mermaid diagrams.

Can I export to PDF, Confluence, or Notion?

Reports are generated in Markdown — paste directly into Confluence, Notion, Google Docs, or any Markdown-compatible tool. PDF export is available on the Pro plan.

Which AI models power BA Assistant v2?

Three models: DeepSeek V4 Flash for the 5 specialist agents and the default single-agent modes (fast, cheap), DeepSeek V4 Pro for the Enterprise-mode Team coordinator, and Gemini 3.5 Flash for document/image extraction.

What's new in v2?

Document upload (PDFs + images via Gemini Vision), Interactive Q&A mode (the tool asks clarifying questions before generating), branded PDF export, pre-built fintech templates (loan origination, KYC/AML, payments, trading), and 6 analysis types including a fast 30-90s Comprehensive mode.
