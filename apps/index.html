Whiteboard to Requirements Live · Free

Upload a whiteboard sketch — AI asks clarifying questions, then generates user stories, functional requirements, and Mermaid diagrams. The pipeline: Vision model extracts text and shapes from the image → LLM structures the findings into requirements → Mermaid.js renders the architecture. Built with Streamlit on Hugging Face Spaces.

Pattern: Vision + LLM → Structured Specs

Sarvam Text to Speech Live · Free

Generate natural speech in 11 Indian languages with 7 voices. Type text, get streaming audio — simple and fast. Real-time token-by-token streaming: text is sent to the Sarvam AI API, and audio chunks stream back immediately — hear output as it generates, with MP3/WAV download options. Built with Streamlit on Hugging Face Spaces.

India Streaming Finder Live · Free

Find which streaming platform has any movie in India — Netflix, Prime, Hotstar, JioCinema, SonyLIV, Zee5, and more. Enter any movie name and the app queries TMDb to identify the title, then cross-references 7+ Indian streaming platforms for availability with filters for free vs paid, quality (4K/HD), and subscription type. Built with Streamlit on Hugging Face Spaces.

Pattern: Multi-API Aggregation + Search
