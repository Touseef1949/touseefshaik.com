## Monthly review workflow

1. Export Search Console query and landing-page data for the preceding 28 days.
2. Group queries by visitor intent, not by isolated keyword.
3. Compare the groups with the questions above and current page coverage.
4. Prefer updating an existing page when it already serves the intent.
5. Create a new page only when the intent is distinct, evidence-backed, and can include first-hand examples or artifacts.
6. Record the decision, source period, target page, and next review date in this file.
